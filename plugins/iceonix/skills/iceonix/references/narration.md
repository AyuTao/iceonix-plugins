# 口播稿与开拍

把项目里已经聊定的口播脚本交给用户拍摄。默认在 Mac 上用冰爪提词器拍；用户明确说要用手机拍（「发送到 UP100」「手机开拍」「/UP100」）时，才发到 UP100。本章不扫描、不批量加工灵感，也不自动发布。

## 默认：写成项目口播稿

1. 读当前项目文稿和用户本轮明确 `@` 的资料；人设沿用你自己的设定。
2. `get_project` 取项目 `revision`，看项目里是否已有 `narration` 文稿。
3. 没有：`create_project_document`，`role=narration`，`content` 为完整口播脚本。
4. 已有：`get_project_document` 读最新 `documentRevision`，再 `update_project_document` 更新原文。**不要新建第二份 narration**，多份口播稿会让提词器要求用户手动选稿。
5. 只回报「口播稿已写入项目」和标题，并提示：在冰爪项目文稿上右键「开拍」，就会带提词器倒计时录制。不要触发录制或发布。

## 手机拍：发送到 UP100

1. 准备不超过 16 字且不含标点的标题、完整口播脚本、可选的拍摄建议，以及一套发布正文和标签；不要生成各平台常驻副本。
2. 用户还没看过最终内容时，先展示标题、脚本和拍摄建议，等他确认。当前指令已要求发送、且这份脚本在对话里已确认过时，不重复询问。
3. 调用 `save_up100_plan`，传 `confirmed=true`、当前项目的绝对路径 `projectPath` 和最终内容。
4. 只回报「已发送到 UP100 待拍」和标题。不触发发布，不新建第二个冰爪项目。

## 边界

- 项目文稿只通过 `create_project_document` / `update_project_document` 写入；`save_up100_plan` 只用于手机拍。不要用 shell 或 `write_file` 直接改项目文档或 `Inspirations/Plans`。
- `save_up100_plan` 每次写一份新的方案，不覆盖已有方案。
- 没有工具能指定提词稿或启动录制，开拍必须由用户在冰爪里点击：这是屏幕、摄像头和麦克风授权的边界。
- UP100 导出的成片只进入项目或收件箱，不会自动发布。
